# 기술 문서

## 디스크 구성
- `PSP_GAME/SYSDIR/EBOOT.BIN`: 암호화된 실행 파일. 복호화하면 고정 주소 ELF(로드 주소 0x08804000, 파일 오프셋 = 주소 + 0xC0). 패치는 복호화한 실행 파일을 그대로 넣습니다.
- `USRDIR/Script/*.blt`: 대본 75개(그중 1개는 개발용 시험 대본).
- `USRDIR/Font/font.gim`: 메시지 글꼴.
- ISO는 제자리 수정하고, 커진 파일은 이미지 끝에 붙입니다(`tools/isobuild.py`).

## BLT 대본
- 헤더: `BLT\0`, 0xEA60, 구역 오프셋 4개, 구역 크기 4개.
- 구역 1 = 명령, 구역 2 = 구역 3 안의 u32 바이트 오프셋, 구역 3 = 0x8000으로 끝나는 u16 글자 번호 문자열, 구역 4 = 파일 이름.
- 제어 코드: 0x8001 줄바꿈, 0x8005·0x8008 효과 태그(JSON에서는 `<5>`, `<8>`). 끝은 16바이트 단위로 채웁니다.
- `tools/blt.py`는 75개 대본 모두 바이트 단위로 똑같이 왕복합니다.

## 글꼴
- `font.gim`: 288×504, 8bpp, 스위즐, 8프레임. 칸 18×18, 16열, 프레임당 448자. 프레임 f는 팔레트 f를 쓰며 프레임 1~6은 인덱스 0~127, 0과 7은 128~255를 씁니다. 그래서 알파→인덱스 대응표를 프레임별로 만듭니다(`tools/kfont.py`).
- 글자 번호 순서: JIS 1~47구(SJIS 순) + 亜 앞 추가 글자 74개 + 끝 5자, 모두 3,568자(`tools/jtab.py`).
- 히라가나(ぁ, 209번)부터 뒤 칸을 KS X 1001 한글 2,350자와 대본에 나오는 추가 한글로 채웁니다. 각 프레임의 0~9번 칸(공백 、。，．・：；？！)은 문장부호로 남깁니다.
- 13px 나눔스퀘어네오를 14×14 영역 가운데에 그립니다(14px 이상은 아랫부분이 잘림).

## 실행 파일 수정
- **글자 배치**(0x0884F3DC 부근 렌더러): 원래 x = 열 번호 × (자간 + 14)였던 것을 픽셀 누적 방식으로 바꾸고, 칸 번호 % 448 < 10인 문장부호는 절반 폭만 전진합니다(0x4B470, 0x4B554).
- **시스템 메시지**: UTF-8 문자열 31개를 원래 바이트 길이 안에서 번역. 세이브 데이터 제목·부제 문자열은 바꾸면 "유저 데이터가 손상되었습니다"가 나오므로 원문을 유지합니다.
- **메모리**: 게임은 VPL 3개(HeapGlobal 16MB, HeapSound 4MB, HeapVoice 1MB)를 만듭니다. 진행 순서에 따라 새 게임 시작 시 HeapGlobal이 바닥나 첫 대본을 읽지 못하고, 실패한 경우 0번지에 strcpy해서 멈춥니다(0x0883E0B4). 풀 크기 표(0x9B6D8)를 24MB로 늘리고 PARAM.SFO에 `MEMSIZE=1`을 넣어 확장 메모리를 씁니다.

## 그림 글자
- GIM은 여러 그림·여러 프레임을 가질 수 있습니다(프레임 수 +0x2E, 오프셋 표 +0x30). 선택 강조처럼 프레임마다 다른 그림이 있어 모든 프레임에 같은 한글을 그립니다(`tools/gim.py`, `tools/images.py`).
- 원문을 지우고 한글을 그린 뒤 원래 팔레트로 다시 양자화하며, 파일 크기는 원본과 같습니다.

## 타이틀 로고
- `Menu/title/title.gim` 12번 그림(로고+리본)을 새로 그립니다: 체크무늬 채움(세로 그라데이션+대각선 줄무늬), 갈색 선·흰 테·검은 외곽을 겹치고, 리본은 원래 픽셀을 살려 글자만 지운 뒤 부제를 기울여 씁니다(`op_titlelogo`).
- 홈 메뉴 ICON0·PIC1은 원래 로고 위치(템플릿 매칭으로 구한 축척·좌표)를 지우고 새 로고를 붙인 뒤, 영어 문구 부분만 원래 픽셀로 되돌립니다(`home_pngs`).

## 확인 방법
PPSSPP 원격 디버거(`tools/ppsspp_rpc.py`, `tools/emu.py`)로 버튼 입력·화면 캡처·메모리 읽기를 자동화하고, `tools/mdis.py`(capstone)로 실행 파일을 역어셈블해 추적했습니다.
